QUICKRIDE iPHONE WEB DEMO

1. This is a browser demo only. It uses local in-memory sample rides.
2. It has no real user accounts, cloud database, GPS, payments, or live rider matching.
3. To test: open index.html in a browser that supports local files, or publish the files to a static web host.
4. To add to iPhone Home Screen after hosting: open the website in Safari > Share > Add to Home Screen.
5. Do not use this demo for real passengers or paid rides.
